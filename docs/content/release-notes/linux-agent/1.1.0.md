# Linux agent 1.1.0

*2026-11-25* · tag `agent-linux-1.1.0`

- **Container logs**: with `LOGS=1` the agent reads the logs of pods (Kubernetes `pods/log`), Swarm tasks and Docker containers for the hub, and the last lines of what is crashing. Off unless the source was added with *Allow reading container logs*. [Logs](../../using/logs.md)
- The hub's **base path**: `HUB_URL` may carry a path (`https://host/hermes`), for a hub behind a proxy on a sub-path.
- **Node location** (`NODE_LOCATION`) is sent with the node.
- Needs hub 1.1.0 for the logs; works with older hubs without them.
